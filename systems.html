WiFi billing systems

Conzanet WiFi, Konnekti WiFi

What it is
A web billing system that lets a WiFi business sell internet access and collect payment, with the router managed from the same place.
Who it’s for
ISPs and hotspot owners who run MikroTik routers, including businesses with several locations.
What it does
Sells hotspot packages and PPPoE subscriptions, takes payment through M-Pesa STK Push, and connects to MikroTik RouterOS to manage customers’ access. Multi-location setups run from one system.
Built with
  • PHP
  • MySQL
  • MikroTik RouterOS
  • M-Pesa STK Push

WavuPay

Payments for tenants

What it is
A payment system that collects money on behalf of businesses and passes it on to them.
Who it’s for
Tenant businesses that want customers’ M-Pesa payments to reach their own till, paybill or phone number.
What it does
Payments come in through M-Pesa C2B to the system first, are recorded per tenant, then settled to each tenant’s till, paybill or phone number.
Built with
  • M-Pesa C2B
  • Multi-tenant

Shule Manager

School management system

What it is
A school management system built around the Kenyan curriculum, where many schools use one platform.
Who it’s for
Kenyan schools, each with its own private space. Schools pay through subscriptions.
What it does
Organises school work into modules, gives every school its own data, and handles subscriptions. It started in PHP and MySQL and is being rebuilt in React, Node.js and Supabase.
Built with
  • PHP
  • MySQL
  • React
  • Node.js
  • Supabase

Boda Boda SACCO system

Rider and SACCO management

What it is
A management system for boda boda SACCOs, the savings groups motorcycle taxi riders belong to.
Who it’s for
SACCO officials and stage chairmen who need to keep track of their riders.
What it does
Holds the rider registry and the SACCO’s modules, with a role for stage chairmen. It is being rewritten from PHP into a modern React, Vercel and Supabase setup.
Built with
  • React
  • Vercel
  • Supabase
